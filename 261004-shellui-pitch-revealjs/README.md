# Shellui pitch (reveal.js)

The same Shellui product pitch as `261004-shellui-pitch-openslide`, built with [reveal.js](https://revealjs.com/).

## Local preview

From this folder:

```bash
pnpm install
pnpm start
```

Open http://localhost:5173

`pnpm start` prints that URL. Speaker notes: press `S`. PDF: open http://localhost:5173/?print-pdf and print (margins none, background graphics on).
