# slides

[Vibehuus ShellUI deck](https://sebastienbarbier.github.io/slides/) — built with [reveal.js](https://revealjs.com/).

## Local preview

```bash
cd 260505-vibehuus-shellui
npm install
npm start
```

Open http://localhost:5173

## GitHub Pages

On every push to `main`, [GitHub Actions](.github/workflows/deploy-pages.yml) installs dependencies and publishes the deck to GitHub Pages.

**One-time setup** (repo settings):

1. **Settings → Pages → Build and deployment**
2. Set **Source** to **GitHub Actions**

Published URL: **https://sebastienbarbier.github.io/slides/**
